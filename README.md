# Αικατερίνη Λαζαρίδου — Ψυχολόγος

Προσωπική ιστοσελίδα. Ένα αρχείο HTML, χωρίς build, χωρίς εξαρτήσεις.

Ζωντανά στο <https://laikateri.github.io/>

Το repo λέγεται `laikateri.github.io` επειδή αυτό είναι το **user site** του
λογαριασμού: σερβίρεται στη ρίζα, χωρίς υποφάκελο στο URL. Όλα τα αρχεία
αναφέρονται σχετικά (`./εικόνα.jpg`), οπότε αν κάποτε μπει δικό της domain
δεν χρειάζεται καμία αλλαγή στον κώδικα.

## Αρχεία

| Αρχείο | Τι είναι |
| --- | --- |
| `index.html` | Όλο το site (HTML + CSS) |
| `CV_Aikaterini_Lazaridou.pdf` | Αναλυτικό βιογραφικό, από το κουμπί στο «Ποια είμαι» |
| `katerina.jpg` | Πορτρέτο |
| `illustration.jpg` | Εικονογράφηση «Η αλλαγή δεν συμβαίνει γραμμικά» |
| `logo.png` | Λογότυπο therapy voices (footer) |
| `mark.png` | Το σήμα χωρίς κείμενο (nav) |
| `favicon.ico`, `favicon.png`, `apple-touch-icon.png` | Εικονίδια καρτέλας και κινητού |

## Επικοινωνία στο site

Δεν υπάρχει φόρμα — μόνο τηλέφωνο, e-mail και Instagram DM. Αυτό σημαίνει ότι το site
**δεν συλλέγει κανένα προσωπικό δεδομένο**, οπότε δεν χρειάζεται πολιτική απορρήτου
ούτε cookie banner. Αν κάποτε προστεθεί φόρμα ή Google Analytics, θα χρειαστούν και τα δύο.

## Στοιχεία που θέλουν επιβεβαίωση

Γραμμένα με λογικές προεπιλογές — δικά της να τα πει:

- Διάρκεια συνεδρίας: **50 λεπτά**
- Συχνότητα: **μία φορά την εβδομάδα** στην αρχή
- Κόστος: «συζητείται στην πρώτη επικοινωνία». Αν θέλει να το δημοσιεύσει, αλλάζει στις Ερωτήσεις
- Διεύθυνση γραφείου: δεν υπάρχει. Αν έχει χώρο, μπαίνει με χάρτη στην Επικοινωνία

## Ανέβασμα αλλαγών

```
cd ~/Documents/katerina-site
git add -A
git commit -m "περιγραφή της αλλαγής"
git push
```

Το GitHub Pages ξαναχτίζει μόνο του σε ένα-δύο λεπτά.

## Αλλαγές

Όλα στο `index.html`, με ελληνικά σχόλια ανά ενότητα. Σειρά: hero, δυσκολίες,
ποια είμαι, απόσπασμα, προσέγγιση, υπηρεσίες, δια ζώσης/διαδικτυακά, πώς ξεκινάμε,
ερωτήσεις, επικοινωνία.

Χρώματα και γραμματοσειρές ορίζονται μία φορά στο `:root` στην αρχή του `<style>`.

## Εικόνες

Η εικονογράφηση και το λογότυπο είναι φωτογραφίες από οθόνη, οπότε έχουν λίγο κόκκο.
Αν υπάρχουν τα πρωτότυπα exports, αντικατέστησε τα `illustration.jpg` και `logo.png`.
